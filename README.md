# earl-databricks-workshop-ai-functions

Sample datasets staged for a Databricks AI Functions workshop.

## Contents

- `complaints_sample.csv` — 831 consumer complaint records with narratives, stratified across 11 CFPB product categories.
- `invoices_workshop.zip` — 25 single-page invoice PDFs, converted from sampled JPGs, for OCR/document-processing exercises.

These are small derived samples for workshop use, not full copies of the source datasets.
